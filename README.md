# Řemeslník Expres

Vytvořit webovou aplikaci a landing page pro concierge MVP služby na expresní objednání řemeslníků (Foodora pro řemeslníky / havárie a drobné opravy s rychlým dojezdem v Praze).

Specifikace a funkce:
1. Moderní, důvěryhodná landing page:
   - Hero sekce: jasný příslib „Řemeslník nebo hodinový manžel u vás do 60–90 minut“, odpočet / garance dostupnosti v Praze.
   - Výběr oborů: Voda a odpady, Elektro, Zámečník (otevírání dveří), Hodinový manžel (montáž, drobné opravy, vrty).
   - Jak to funguje: 1. Zadáte požadavek -> 2. Dispečink obratem spojí nejbližšího volného mistra -> 3. Do hodiny je u vás, platíte až po hotové práci.
2. Expresní poptávkový formulář pro zákazníka:
   - Typ problému (havárie ihned vs. drobná oprava dnes)
   - Lokalita v Praze (adresa, městská část)
   - Popis závady s možností nahrát fotku
   - Telefonní číslo pro okamžité potvrzení
3. Transparentní ceník:
   - Pevný startovní výjezdní poplatek (doprava a diagnostika) + transparentní hodinové sazby dle řemesla.
4. Přihláška pro řemeslníky:
   - Sekce pro řemeslníky „Přidejte se do sítě“ s formulářem pro registraci (obor, lokalita působení, telefon).
5. Dispečerská nástěnka (Concierge Dashboard):
   - Přehled nových urgentních poptávek s možností simulovat broadcast na řemeslníky a změnu stavu zakázky (Nová -> Oslovování -> Přijato řemeslníkem -> Na cestě -> Dokončeno).
